# Coke-Sales-Analysis
Project Details - Coke Sales Analysis using Excel
Project Description:
This project focuses on analyzing Coca-Cola sales data across key American retailers using Excel. The objective is to extract actionable insights from transactional and operational metrics like total sales, units sold, and operating margin. The analysis dives into regional performance, retailer efficiency, and sales trends to identify areas of strength and opportunities for improvement.

 

The analysis aims to understand:

How Coca-Cola sales vary by retailer, region, and time
The relationship between pricing, volume, and profitability
Trends in operating margins across different markets
 

Project Implementation:
Data Preparation:

Load and review the multi-sheet Excel dataset
Standardize column names and clean noisy headers
Handle missing or incorrect data entries
Convert data types as needed (e.g., dates, numeric fields)
Structure key metrics such as sales, units, and margins
 

Sales & Profitability Analysis:

Analyze unit sales, revenue, and profit across retailers and regions
Compare price per unit and its influence on total sales
Identify top-performing and underperforming locations using operating margin
 

Time-based Analysis:

Aggregate monthly sales and observe trends throughout the year
Detect seasonal patterns and peak sales periods
Track changes in profitability metrics over time
 

Data Visualization:

Create bar charts for retailer comparisons
Use line graphs to visualize monthly trends
Generate heatmaps to reflect regional sales performance
Build pivot tables and slicers for interactive exploration
